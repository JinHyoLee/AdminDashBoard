# SaaS Admin Dashboard

CRUD 중심의 SaaS 관리자 대시보드.
사용자·상품·주문을 관리하고, 쌓인 데이터를 집계해 대시보드와 통계로 보여주는 것을 목표로 함.

## 기술 스택

- React 18 + TypeScript
- Vite
- Zustand (상태 관리, `persist`로 브라우저 localStorage에 저장)
- API 연동이 필요해지면 TanStack Query를 추가할 예정임

## 실행

```bash
npm install
npm run dev
```

## 구현된 기능

### Users (사용자 관리)

- 사용자 추가 · 수정 · 삭제 · 상세보기 (모달)
- 이름 · 이메일 검색
- 컬럼 헤더 클릭으로 오름차순/내림차순 정렬
- 페이지당 10명씩 페이징
- 유효성 검사: 이름 필수, 이메일 형식, 이메일 중복(대소문자 구분 없음)
- 가입일은 추가할 때 자동으로 입력됨
- 샘플 사용자 25명이 기본으로 들어 있음

### Products (상품 관리)

- 상품 등록 · 수정 · 삭제 · 상세보기 (모달)
- 상품명 검색 + 카테고리 필터 (함께 적용 가능)
- 상품명 · 카테고리 · 가격 · 재고 정렬 (가격·재고는 숫자 기준)
- 이미지 업로드: JPG · PNG · WEBP만 허용, 미리보기와 삭제 가능
  - localStorage 용량(약 5MB) 때문에 최대 400px로 줄이고 JPEG로 압축해 저장함
- 상태는 따로 저장하지 않고 재고로 계산함: 재고 0이면 품절, 아니면 판매 중
- 유효성 검사: 상품명 필수, 가격·재고는 0 이상의 정수
- 카테고리: 전자제품 · 의류 · 식품 · 생활용품 · 도서
- 샘플 상품 15개가 기본으로 들어 있음

### Orders (주문 관리)

- 주문 목록 · 상세 페이지 (주문 생성·삭제는 범위에서 제외함)
- 상태 탭 필터: 전체 · 대기 · 결제 · 배송 · 완료 (탭마다 건수 표시)
- 주문번호 · 고객명 검색, 주문일 · 결제금액 정렬, 페이지당 10건 페이징
- 상세 페이지: 진행 단계 표시, 고객 정보, 주문 상품(단가 · 수량 · 소계), 합계
  - 라우터 없이 목록 화면 안에서 상세 화면으로 전환하며, 돌아오면 탭·검색 상태가 유지됨
- 상태 변경: 대기 → 결제 → 배송 → 완료 순서로 한 단계씩만 진행함
- 재고 연동: 결제로 바뀔 때 주문 수량만큼 상품 재고를 차감함
  - 재고가 부족하면 결제로 넘어가지 않고 부족한 상품과 수량을 보여줌
  - 재고가 0이 되면 Products에서 자동으로 품절로 표시됨
- 고객명 · 상품명 · 단가는 주문 시점 값을 주문 안에 복사해 둠
  - 나중에 사용자나 상품을 삭제하거나 가격을 바꿔도 과거 주문은 그대로 유지됨
- 결제금액은 저장하지 않고 단가 × 수량의 합으로 계산함
- 샘플 주문 15건이 기본으로 들어 있음 (1월~11월, 품절 상품이 든 주문 1건 포함)

## 트러블슈팅

### 1. 사용자나 상품을 삭제하면 과거 주문이 깨짐 (Orders)

- **문제**: 주문에 사용자 id, 상품 id만 저장하면, 해당 사용자나 상품을 삭제하는 순간 주문 화면에서 고객명과 상품명이 사라짐. 상품 가격을 바꾸면 과거 주문 금액까지 바뀜
- **원인**: 주문이 다른 데이터를 참조만 하고 있어서, 원본이 바뀌면 함께 영향을 받음
- **해결**: 주문 시점의 고객명, 상품명, 단가를 주문 안에 복사해 둠. 사용자·상품이 삭제되거나 가격이 바뀌어도 과거 주문은 그대로 유지됨
- **관련 코드**: `types/order.ts`의 `OrderItem`, `customerName`

### 2. 마지막 페이지에서 삭제하면 빈 페이지가 보임 (Users)

- **문제**: 3페이지의 사용자를 모두 삭제하면 전체 페이지는 2개로 줄었는데, 화면은 비어 있는 3페이지에 머무름
- **원인**: 현재 페이지 번호(`page`)는 그대로인데 전체 페이지 수만 줄어듦
- **해결**: 화면에 쓸 페이지를 `Math.min(page, totalPages)`로 계산해, 페이지 수를 넘으면 자동으로 마지막 페이지를 보여주도록 함. 검색어를 바꿀 때도 1페이지로 돌아가게 함
- **관련 코드**: `UsersPage.tsx`의 `currentPage`

## 폴더 구조

```
src/
  components/
    layout/   Header, Sidebar
    common/   PageHeader, Placeholder, Modal, Pagination
  pages/      각 메뉴 페이지 + UserFormModal, ProductFormModal, OrderDetail
  stores/     navStore (현재 메뉴), userStore, productStore, orderStore
  types/      user, product, order (데이터 모양 정의)
  utils/      format (금액 표시)
```

## 참고

- 데이터는 브라우저 localStorage에 저장되므로 새로고침해도 유지됨
- 샘플 데이터로 초기화하려면 개발자도구 → Application → Local Storage에서
  `admin-users`, `admin-products`, `admin-orders` 항목을 삭제하고 새로고침하면 됨
